# IGCSE Comprehensive Glossary - User Guide

## Overview
This glossary provides exhaustive technical vocabulary from IGCSE syllabi across:
- **Physics**: Motion, Forces, Energy, Particulate Nature, Thermal Energy, Waves, Electricity & Magnetism
- **Chemistry**: Reactions, Acids/Bases, Bonding, Organic, Periodicity, Groups
- **Biology**: Cell Structure, Transport, Photosynthesis, Respiration, Homeostasis, Genetics, Ecology
- **Mathematics (Core & Extended)**: Algebra, Functions, Geometry, Calculus, Statistics
- **Computer Science**: Hardware, Software, Algorithms, Networks, Security

## How Terms Are Organized

### Structure
```
## SECTION (Subject - e.g., PHYSICS, CHEMISTRY)
├── ### UNIT (Topic - e.g., Unit 1: Motion, Forces and Energy)
│   ├── #### 1.1 Subtopic (e.g., Motion and Speed)
│   │   ├── ##### **Term Name**
│   │   │   ├── Definition
│   │   │   └── Attributes Table
```

### Six Attributes Per Term

Each term includes these attributes in a structured markdown table:

| Attribute | Purpose |
|-----------|---------|
| **Definition** | Pedantic, technical definition - no abbreviations |
| **Primary Methodology** | How the concept is taught/demonstrated/measured in classroom |
| **Mathematical Model** | Equations, formulas, all rearrangements, units |
| **Contextual Application** | Real-world examples (minimum 3-4 specific applications) |
| **Examiner Insight** | Common student errors, mark scheme focus points, typical question patterns |
| **Relational Schema** | How this term connects to other concepts (prerequisite → this → advanced) |

## Organization by Subject

### Physics
- **Unit 1**: Motion, Forces, Energy (70+ terms)
  - Speed, Velocity, Acceleration, Graphs
  - Forces, Newton's Laws, Momentum, Impulse
  - Work, Energy (kinetic, potential), Power, Efficiency
  
- **Unit 2**: Particulate Nature of Matter (50+ terms)
  - Atoms, Molecules, Ions, Electrons, Protons, Neutrons
  - States of Matter, Phase Transitions, Density
  - Kinetic Theory, Gas Laws, Diffusion, Effusion
  
- **Unit 3**: Thermal Energy (40+ terms)
  - Internal Energy, Heat, Temperature
  - Specific Heat Capacity, Latent Heat, Calorimetry
  - Thermodynamics (1st & 2nd Laws), Entropy
  
- **Unit 4**: Waves and Sound (35+ terms)
  - Wave Properties, Wavelength, Frequency, Amplitude
  - Transverse vs. Longitudinal, Sound, Ultrasound
  - Reflection, Refraction, Diffraction, Interference
  - Doppler Effect, Polarization
  
- **Unit 5**: Electricity & Magnetism (60+ terms)
  - Electric Charge, Fields, Potential Difference
  - Current, Resistance, Ohm's Law, Power
  - Electromagnetism, Electromagnetic Induction, Transformers

### Chemistry
- **Unit 1**: Chemical Change (35+ terms)
  - Reactions, Balancing, Exothermic/Endothermic
  - Activation Energy, Catalysts, Reaction Rates
  - Equilibrium, Le Chatelier's Principle
  
- **Unit 2**: Acids, Bases, Salts (30+ terms)
  - Acid/Base definitions, pH Scale
  - Neutralization, Buffers, Indicators
  - Titrations, Salt Hydrolysis
  
- **Unit 3**: Bonding & Structure (35+ terms)
  - Chemical Bonds (covalent, ionic, metallic)
  - Electronegativity, Bond Polarity, Molecular Polarity
  - Lewis Structures, VSEPR Theory
  - Crystal Structures, Properties
  
- **Unit 4**: Organic Chemistry (50+ terms)
  - Alkanes, Alkenes, Alkynes, Alcohols
  - Carboxylic Acids, Esters, Polymers
  - Isomerism, Reaction Types, Functional Groups
  
- **Unit 5**: Periodicity & Groups (40+ terms)
  - Periodic Table Trends
  - Groups 1, 2, 17 (halogens), Noble Gases
  - Transition Metals, d-Block Elements

### Biology
- **Unit 1**: Cell Structure (30+ terms)
  - Prokaryotic vs. Eukaryotic cells
  - Organelles (nucleus, mitochondria, chloroplasts, ER, Golgi, etc.)
  - Cell Membrane, Transport across Membranes
  
- **Unit 2**: Transport (20+ terms)
  - Diffusion, Osmosis, Active Transport
  - Xylem and Phloem Transport
  - Exchange Surfaces
  
- **Unit 3**: Photosynthesis (25+ terms)
  - Light-Dependent Reactions, Light-Independent Reactions
  - Chlorophyll, Photolysis, Calvin Cycle
  - Limiting Factors
  
- **Unit 4**: Respiration (25+ terms)
  - Aerobic Respiration, Anaerobic Respiration
  - Glycolysis, Krebs Cycle, Electron Transport Chain
  - ATP, Mitochondrial Structure
  
- **Unit 5**: Homeostasis & Control (30+ terms)
  - Osmoregulation, Thermoregulation, Excretion
  - Nervous System, Hormones, Reflex Arcs
  - Feedback Mechanisms
  
- **Unit 6**: Genetics & DNA (35+ terms)
  - DNA Structure, Replication, Transcription, Translation
  - Genes, Alleles, Genetic Crosses
  - Mitosis, Meiosis, Fertilization
  - Inheritance Patterns
  
- **Unit 7**: Ecology (25+ terms)
  - Ecosystems, Food Chains, Food Webs
  - Populations, Competition, Succession
  - Conservation, Human Impact

### Mathematics
- **Core Content** (60+ terms)
  - Number Systems, Arithmetic, Percentages
  - Algebra (equations, polynomials, inequalities)
  - Linear Functions, Quadratic Functions
  - Trigonometry (sine, cosine, tangent)
  - Statistics (mean, median, mode, standard deviation)
  - Probability
  - Geometry (shapes, areas, volumes)
  
- **Extended Content** (30+ terms)
  - Exponential & Logarithmic Functions
  - Calculus (limits, derivatives, integrals)
  - Advanced Trigonometry
  - Vectors
  - Complex Numbers

### Computer Science
- **Hardware & Data** (25+ terms)
  - CPU, Memory (RAM, ROM), Storage
  - Data Representation (binary, hex, bytes)
  - Logic Gates, Boolean Algebra
  
- **Software & Programming** (35+ terms)
  - Programming Concepts, Data Types
  - Control Structures, Functions
  - Object-Oriented Concepts
  - Database Design
  
- **Algorithms** (20+ terms)
  - Searching Algorithms, Sorting Algorithms
  - Algorithm Complexity, Big O Notation
  
- **Networks & Security** (25+ terms)
  - Network Protocols, TCP/IP
  - Encryption, Hashing, Digital Signatures
  - Cybersecurity Threats, Defenses
  - HTML, CSS, Web Technologies
