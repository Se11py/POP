# A Level Computer Science (9618) Flashcards

## [A LEVEL] UNIT 1: INFORMATION REPRESENTATION
- **Front**: Two's Complement
  **Back**: A method of representing negative integers in binary where the MSB has a negative weight.
- **Front**: Floating Point Representation
  **Back**: A way to represent real numbers using a mantissa and an exponent.
- **Front**: Unicode
  **Back**: A universal character encoding standard that can represent text in all of the world's languages.
- **Front**: Pixel
  **Back**: The smallest addressable element in a bitmap image.
- **Front**: Resolution
  **Back**: The number of pixels per unit length (e.g., DPI) or the total number of pixels in an image (width x height).
- **Front**: Sampling Rate
  **Back**: The number of samples of sound taken per second, measured in Hz.
- **Front**: Lossless Compression
  **Back**: A compression algorithm where the original data can be perfectly reconstructed from the compressed data (e.g., RLE).
- **Front**: Lossy Compression
  **Back**: A compression algorithm that permanently discards some data to reduce file size (e.g., JPEG).

## [A LEVEL] UNIT 3: HARDWARE
- **Front**: Von Neumann Architecture
  **Back**: A computer architecture based on the concept of storing program instructions and data in the same memory unit.
- **Front**: Fetch-Execute Cycle
  **Back**: The basic operational process of a CPU: Fetching an instruction from memory, decoding it, and executing it.
- **Front**: Program Counter (PC)
  **Back**: A register that holds the memory address of the next instruction to be fetched.
- **Front**: Current Instruction Register (CIR)
  **Back**: A register that holds the instruction currently being decoded and executed.
- **Front**: Memory Address Register (MAR)
  **Back**: A register that holds the address of the memory location currently being accessed.
- **Front**: Memory Data Register (MDR)
  **Back**: A register that holds the data item being transferred to or from memory.
- **Front**: Accumulator (ACC)
  **Back**: A general-purpose register used to store the results of arithmetic and logical operations.
- **Front**: ALU (Arithmetic Logic Unit)
  **Back**: The part of the CPU that performs arithmetic (add, subtract) and logical (AND, OR, NOT) operations.
- **Front**: RISC vs CISC
  **Back**: RISC (Reduced Instruction Set Computer) uses a small set of simple instructions; CISC (Complex Instruction Set Computer) uses a large set of complex instructions.

## [A LEVEL] UNIT 2: COMMUNICATION & NETWORKING
- **Front**: IP Address
  **Back**: A unique numerical label assigned to each device connected to a computer network.
- **Front**: MAC Address
  **Back**: A unique hardware identifier assigned to a network interface controller (NIC).
- **Front**: Client-Server Model
  **Back**: A network architecture where clients request resources and a central server provides them.
- **Front**: Peer-to-Peer (P2P) Model
  **Back**: A network architecture where all nodes have equal status and can share resources directly.
- **Front**: TCP/IP Suite
  **Back**: A set of protocols used for communication over the internet, consisting of 4 layers: Application, Transport, Internet, and Link.

## [A LEVEL] UNIT 8: DATABASES
- **Front**: Relational Database
  **Back**: A database structured to recognize relations among stored items of information, using multiple linked tables.
- **Front**: Primary Key
  **Back**: A field (or set of fields) that uniquely identifies each record in a table.
- **Front**: Foreign Key
  **Back**: A field in one table that links to the primary key in another table.
- **Front**: Normalization
  **Back**: The process of organizing data in a database to reduce redundancy and improve data integrity.
- **Front**: 1NF (First Normal Form)
  **Back**: A table is in 1NF if all attributes are atomic and there are no repeating groups.
- **Front**: 2NF (Second Normal Form)
  **Back**: A table is in 2NF if it is in 1NF and every non-key attribute is fully functionally dependent on the primary key.
- **Front**: 3NF (Third Normal Form)
  **Back**: A table is in 3NF if it is in 2NF and there are no transitive dependencies.

## [A LEVEL] UNIT 9: ALGORITHM DESIGN
- **Front**: Recursion
  **Back**: A programming technique where a function calls itself to solve a smaller sub-problem until a base case is reached.
- **Front**: Big O Notation
  **Back**: A mathematical notation used to describe the limiting behavior of an algorithm's time or space complexity as the input size grows.
- **Front**: Binary Search Complexity
  **Back**: O(log n).
- **Front**: Bubble Sort Complexity
  **Back**: O(n²).
- **Front**: Linked List
  **Back**: A dynamic data structure consisting of nodes where each node contains data and a pointer to the next node.
- **Front**: Stack (LIFO)
  **Back**: A Last-In-First-Out data structure where elements are added and removed from the same end.
- **Front**: Queue (FIFO)
  **Back**: A First-In-First-Out data structure where elements are added at the rear and removed from the front.
